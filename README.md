# O'krasa Flowers&coffee — сайт

Одностраничный сайт кав'ярні O'krasa Flowers&coffee (Вінниця). Мова сайту: українська.

Мета сайту: привести більше гостей. Тому на першому екрані кнопки «Дивитись меню», «Прокласти маршрут» і дзвінок, а на телефоні знизу завжди видно «Зателефонувати» й «Маршрут».

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Сам сайт (HTML, стилі й скрипт в одному файлі) |
| `screen.png` | Знімок готового сайту |
| `vercel.json` | Налаштування для хостингу Vercel |
| `DEPLOYMENT.md` | Як опублікувати сайт |
| `DESIGN.md` | Кольори, шрифти, структура сторінки |
| `roadmap.md` | Що ще треба додати й покращити |
| `mcp_config.json` | Приклад конфігу MCP-сервера 21st.dev (ключ замінено на заглушку) |
| `photos/` | Папка для фото кав'ярні |

## Структура сторінки

1. Шапка з навігацією та кнопкою «Зателефонувати»
2. Перший екран: «Кава, що пахне квітами»
3. Меню: кава, сезонні напої, десерти, vegan-меню
4. Атмосфера: кава й живі квіти в інтер'єрі
5. Відгуки з Google Maps (рейтинг 4,8, 51 відгук)
6. Як знайти: адреса, години, телефон, соцмережі, карта

## Як додати фото

Покладіть 4–6 фото в папку `photos/` з іменами `1.jpg` … `6.jpg`. Секція з галереєю з'явиться на сайті сама. Якщо фото немає, секції просто не видно.

## Що треба перевірити перед публікацією

- Адреса «вул. Стрілецька, 1а» взята з каталогів компаній, перевірте її.
- Години роботи: у Google вказано відкриття о 09:00 у суботу, у каталогах «08:00–21:00 без вихідних». Впишіть актуальні.
- Меню поки без назв страв і цін, див. `roadmap.md`.

## Джерела даних

Назва, телефон, рейтинг, ціновий діапазон і відгуки взяті з картки закладу в Google Maps. Адреса, категорії меню й соцмережі взяті з каталогів dovidka.com та relaxi.info.
