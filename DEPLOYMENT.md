# Як опублікувати сайт

Сайт статичний (один `index.html`), тому його можна безкоштовно розмістити на будь-якому з сервісів нижче. Найпростіше Vercel або Netlify.

## Варіант 1. Vercel (рекомендовано)

1. Зареєструйтесь на vercel.com (можна через Google або GitHub).
2. Натисніть **Add New → Project**.
3. Завантажте папку з проєктом (або підключіть GitHub-репозиторій).
4. Framework Preset: **Other**. Build Command і Output Directory залиште порожніми.
5. Натисніть **Deploy**. Через хвилину сайт буде доступний за адресою на кшталт `okrasa.vercel.app`.

Файл `vercel.json` уже налаштований, нічого змінювати не треба.

Через термінал (якщо встановлено Node.js):

```
npm i -g vercel
cd папка-з-проєктом
vercel --prod
```

## Варіант 2. Netlify

1. Відкрийте app.netlify.com/drop.
2. Перетягніть у вікно всю папку з проєктом.
3. Сайт буде опубліковано одразу.

## Варіант 3. GitHub Pages

1. Створіть репозиторій на GitHub і завантажте файли.
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Адреса сайту: `https://ваш-нік.github.io/назва-репозиторію/`.

## Власний домен

1. Купіть домен (наприклад, `okrasa.vn.ua`).
2. У налаштуваннях Vercel або Netlify відкрийте **Domains** і додайте домен.
3. У реєстратора домену впишіть DNS-записи, які покаже сервіс.

## Після публікації (важливо для клієнтів)

1. Додайте посилання на сайт у профіль Google Maps: **Додати сайт** у картці закладу. Це найкраще, що можна зробити, щоб гості переходили на сайт.
2. Додайте посилання в шапку профілю Instagram і Facebook.
3. Перевірте сайт на телефоні: кнопки «Зателефонувати» й «Маршрут» мають працювати.
4. Перевірте, що карта у блоці «Як знайти» показує правильне місце.
